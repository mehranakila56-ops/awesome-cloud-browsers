# Contributing to Awesome Cloud Browsers

First off, thank you for considering contributing! This list exists because of people who care about helping the community discover quality tools.

## What Belongs Here

This list focuses on:
- **Cloud browser platforms** — services you call via API to get managed browser sessions
- **Browser automation frameworks** — Puppeteer, Playwright, Selenium, etc.
- **AI-native browser tools** — APIs and agents that use browsers for AI workflows
- **MCP browser servers** — giving AI assistants browser access via Model Context Protocol
- **Anti-detection tools** — stealth plugins, proxy services, CAPTCHA solvers

**Not included:**
- General web scraping tools that don't involve actual browser automation
- Outdated projects (no commit in 2+ years)
- Pure marketing pages with no real technical product

## Adding an Entry

1. **Fork** this repository
2. **Find the right section** — add your entry alphabetically within its section
3. **Format correctly:**
   ```
   - [Name](URL) - One sentence description. Focus on what it does, not marketing language.
   ```
4. **Open a PR** with the title: `Add [Tool Name]`

## Quality Criteria

Before submitting, confirm:
- [ ] The tool is actively maintained (commit in last 12 months)
- [ ] Documentation exists (README or docs site)
- [ ] You've tested or have direct experience with it
- [ ] Description is factual, not marketing copy

## Updating Entries

If you notice an outdated URL, wrong description, or a project that's been abandoned — PRs to fix these are very welcome.

## Questions?

Open an issue if you're unsure where something belongs.
